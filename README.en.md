# Time Management System

[Versão em português](README.md)

Frontend for a time and attendance management system, built with React, TypeScript, and Vite.

## Technologies

- React and TypeScript
- Vite
- Tailwind CSS and DaisyUI
- Material UI
- React Router DOM
- React Hook Form
- Axios / Java Spring REST API integration
- React Hot Toast, React Spinners, and React Icons
- ESLint and Prettier

## Development

```bash
npm install
npm run dev
```

## Build and quality

```bash
npm run build
npm run lint
```

The frontend consumes a Java/Spring REST API. Configure the API URL for the target environment.
